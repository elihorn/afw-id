### Logo type

{% logotypeLayout %}

Logo type may be spaced out vertically, with equal spacing between words. 'Friendly' should be scaled to the width of the page, with 'a' left aligned and 'wave' right aligned.
{% endcolumn %}

### Logo mark

{% logomarkLayout %}

The logo mark should be aligned all the way to an edge of the page, usually bleeding off the bottom-right corner.
